# Bean & Brew Café - Divisão de Trabalho

## Nome do Projeto
**Bean & Brew Café**

## Objetivo do Site
Criar uma cafeteria virtual que transmita os sabores e o ambiente de um café artesanal.

---

## Divisão de Trabalho (Você + Eu)

### Você: 
- **Pesquisa** sobre estilos de design e inspiração no We Coffee
- **Testes** e verificação da página funcionando
- **Captura de prints** para a entrega

### Eu (Codex):
- Criar HTML estruturado com todas as seções
- Criar CSS moderno e responsivo
- Criar JavaScript para interatividade
- Garantir que a paleta de cores esteja aplicada corretamente

## Estrutura da Página Criada

### Páginas/Seções:
1. **Header** - Navbar com logo, menu e redes sociais
2. **Hero** - Banner principal com imagem de fundo
3. **Menu** - Cardápio com cards de cafés
4. **Sobre** - Seção sobre a cafeteria
5. **Team** - Equipe
6. **Testimonials** - Depoimentos com slider
7. **Contact** - Formulário de contato
8. **Footer** - Rodapé com informações
