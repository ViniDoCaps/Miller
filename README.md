# Bean & Brew Café - Página Web

## Objetivo do Trabalho
Desenvolver uma página web para uma cafeteria com identidade visual profissional, inspirada no We Coffee.

---

## Visão Geral do Projeto

### Tema Escolhido: Site de Cafeteria
**Estilo de Design: Minimalista Moderno inspirado no We Coffee**

### Paleta de Cores
- **Principal**: #6F4E37 (Marrom Café)
- **Secundária**: #C4A484 (Marrom Claro)
- **Destaque**: #D4A373 (Ouro Queimado)
- **Fundo**: #F5F5F5 (Cinza Muito Claro)
- **Texto**: #333333 (Preto Acinzetado)

---

## Estrutura do Projeto

### Páginas Planejadas

1. **index.html** - Página Inicial
   - Header com logo e menu
   - Banner hero com imagem de fundo
   - Preview do cardápio
   - Sobre resumido
   - Footer

2. **cardapio.html** - Cardápio
   - Header com menu
   - Seção de cafés clássicos
   - Bebidas especiais
   - Doces artesanais
   - Footer

3. **avaliacoes.html** - Avaliações
   - Header com menu
   - Slider de depoimentos
   - Contador de estrelas
   - Footer

4. **galeria.html** - Galeria
   - Header com menu
   - Grid de imagens do local
   - Footer

---

## Organização por Página

### Cada página terá:
- HTML estruturado
- CSS dedicado (styles.css ou page-specific.css)
- JavaScript interativo (script.js ou page-specific.js)

## Ideias e Notas

### Design Header
- Header dividido em duas partes
- Topo com informações de contato

### Cardápio
- Cards com hover effect
- Grid responsivo
- Precificação clara

### Avaliações
- Carousel automático
- Sistema de estrelas
- Contador visual

### Galeria
- Layout em grid
- Efeitos de zoom hover
- Imagens do café e ambiente
